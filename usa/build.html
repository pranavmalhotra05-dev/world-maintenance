Roofprint 3D · any US address

Type any US address

Builds a 3D block around it from open data: every USGS laser point, building outlines and national records.
Building new addresses needs the local server: python usa/serve.py
Then open http://127.0.0.1:8780/usa/build.html. Blocks that are already built can still be viewed from the map.
The local server is running, but usa/build_block.py is not installed yet, so new addresses cannot be built.
Block size
square, centred on the address (40 / 60 / 100 m half-size)
